# メートル細目ねじ 任意入力 設計仕様

**日付:** 2026-11-24
**対象ファイル:** `thread_cutting.py`、`tests/test_metric_fine_custom.py`(新規)

---

## 目的

M16x1 のように `METRIC_FINE_THREAD` に登録されていないメートル細目ねじを、ソフトを修正せずに使えるようにする。呼び径とピッチを手入力すると、基準寸法と公差域中間値を計算してプログラムを生成する。

## 対象外

- 並目 (M) やメートル以外のねじ種類の任意入力
- 6g / 6H 以外の公差域クラス
- 登録済みサイズの値の変更(下記「既存動作への影響」の M68 を除く)

---

## 操作

- ねじ種類が「メートル細目ねじ (MF)」のときだけ、呼び径コンボボックスを手入力可能(`state="normal"`)にする。他の種類は `readonly` のまま。
- `M16x1` と入力し、Enter またはフォーカス移動で確定する。
- 確定時に表記を正規化する。`m16X1`、`16x1`、`M16×1`、`M16*1` はすべて `M16x1` になる。
- 確定するとピッチ欄にそのピッチが入り、外径/内径欄に公差域中間値が入る。
- 「プログラム生成」を押したときにも確定処理を行う。
- リストにあるサイズを選んだ場合の動作は今までと同じ。

## 入力チェック

次の場合は `ValueError` とし、メッセージボックスで表示して生成しない。Enter と「プログラム生成」のときに表示し、フォーカス移動だけのときは表示しない。

| 条件 | メッセージ |
|------|-----------|
| `M<径>x<ピッチ>` として読めない | `「M16x1」の形式で入力してください。` |
| 径が 1.6〜355 mm の範囲外 | `呼び径は 1.6〜355 mm の範囲で入力してください。` |
| ピッチが 0.2〜8 mm の範囲外 | `ピッチは 0.2〜8 mm の範囲で入力してください。` |
| ピッチ > 径 / 4 | `ピッチが呼び径に対して大きすぎます。` |

径の下限を 1.6 mm とするのは、JIS B 0209-2 が M1.4 以下に別の公差域クラス(5H / 6h)を使うため。

## 計算

### 基準寸法 (JIS B 0205-4)

```
d2 = d − 0.649519 P
d1 = d − 1.226869 P
D1 = d − 1.082532 P
```

小数第3位に丸め、既存データベースと同じ `(d2, d1, D1)` のタプルで扱う。

### 公差 (ISO 965-1 / JIS B 0209-1、公差グレード 6)

ISO 965-1 の公差値は計算式を R40 数列に丸めたものだが、丸め方が一定でなく、計算式だけでは規格表の値を再現できない(登録済みサイズで照合した結果、最大 13 µm の差が出た)。そのため規格表の値をテーブルとして内蔵する。

| テーブル | キー | 内容 |
|----------|------|------|
| `_ISO965_ES_G` | ピッチ | 外ねじ g の上の寸法差 es |
| `_ISO965_TD_6` | ピッチ | 外ねじ外径公差 Td |
| `_ISO965_TD1_6` | ピッチ | 内ねじ内径公差 TD1 |
| `_ISO965_TD2_EXT_6` | (径区分, ピッチ) | 外ねじ有効径公差 Td2 |
| `_ISO965_TD2_INT_6` | (径区分, ピッチ) | 内ねじ有効径公差 TD2 |

径区分は ISO 965-1 の区分(1.4 / 2.8 / 5.6 / 11.2 / 22.4 / 45 / 90 / 180 / 355、「を超え・以下」)を使う。

テーブルにないピッチ、または径区分とピッチの組み合わせ(例: M50x1)は、ISO 965-1 の計算式を R40 数列の最も近い値に丸めて使う。この場合は計算情報欄に概算である旨を表示する。

```
es  = −(15 + 11P)                     µm
Td  = 180 P^(2/3) − 3.15 / √P         µm
Td2 = 90 P^0.4 d^0.1                  µm   (d は径区分の両端の幾何平均)
TD2 = 1.32 × Td2                      µm
TD1 = 433P − 190 P^1.22  (P < 1)      µm
TD1 = 230 P^0.7          (P ≥ 1)      µm
```

### 公差域中間値

```
外ねじ 外径    d_avg  = d  + es − Td / 2
外ねじ 有効径  d2_avg = d2 + es − Td2 / 2
内ねじ 有効径  D2_avg = d2 + TD2 / 2
内ねじ 内径    D1_avg = D1 + TD1 / 2
```

X 目標径、切り込み深さ、切り込み回数の計算は既存の `calc_thread_depth` をそのまま使う。

## 構成

### 追加する関数(GUI に依存しない)

- `parse_metric_fine(text) -> (name, d, pitch)`: 入力文字列を解釈・検証し、正規化した名前を返す。不正なら `ValueError`。
- `metric_basic_dims(d, pitch) -> (d2, d1, D1)`: 基準寸法。
- `_iso965_tol(d, pitch) -> dict`: `es, Td, Td2, TD2, TD1`(mm)と、すべて規格表の値かどうかを示す `exact`。
- `_metric_d_from_name(name) -> float | None`: `M16x1` から 16.0 を取り出す。

### 変更する関数

- `_d2_avg`、`_d_major_avg`、`_D1_minor_avg`: JIS B 0209-2 直接参照テーブル(`_METRIC_EXT_AVG_6G` / `_METRIC_INT_AVG_6H`)に名前がなく、名前が `M` で始まる場合は `_iso965_tol` で計算する。それ以外の経路は変更しない。
- `ThreadCuttingApp`:
  - サイズの検索を `_entries(ttype, size_name)` にまとめ、データベースの該当行に加えて、MF で未登録の名前なら計算した行を返す。`_on_size_change`、`_set_default_diameter`、`_generate` はこれを使う。
  - `_on_type_change` で呼び径コンボボックスの `state` を切り替える。
  - 呼び径コンボボックスに `<Return>` と `<FocusOut>` をバインドし、確定処理 `_commit_size` を呼ぶ。
  - 計算情報欄に、任意入力のときは公差の出典(規格表の値 / 計算式による概算)を1行表示する。

---

## 既存動作への影響

- 登録済みのメートル細目 17 サイズと、並目の M1〜M64 は直接参照テーブルが優先されるため、結果は変わらない。
- 並目 **M68** は直接参照テーブルになく、今までは予備の近似計算(es = −0.038)を使っていた。変更後は ISO 965-1 の値(es = −0.080、Td2 = 0.280)で計算されるため、外径・有効径の中間値が変わる。
- メートル以外のねじ種類は変わらない。

## テスト

`tests/test_metric_fine_custom.py`(pytest):

1. **JIS 表との照合**: `ねじ規格.pdf` の JIS B 0209-2 表1〜4 のうち M1.6 以上の行について、`metric_basic_dims` と `_iso965_tol` から求めた最大・最小寸法が表の値と 0.001 mm 以内で一致する。ソフトに未登録の M18x2、M20x2、M22x2、M42x3、M45x3、M48x3、M52x4、M56x4、M60x4、M64x4 を含む。PDF の誤植と判断した M5 の d2 最小 4.631、M27 の D2 最大 25.306 は除く。
2. **M16x1**: 基準寸法 (15.350, 14.773, 14.917)、d_avg = 15.884、d2_avg = 15.265、D2_avg = 15.430、D1_avg = 15.035。
3. **正規化**: `m16X1`、`16x1`、`M16×1`、` M16 x 1 ` がすべて `("M16x1", 16.0, 1.0)` になる。
4. **不正入力**: `abc`、`M16`、`M1x0.2`、`M400x4`、`M16x10`、`M16x0.1`、`M8x3` が `ValueError`。
5. **概算フラグ**: M16x1 は `exact=True`、M50x1 は `exact=False`。
6. **既存動作**: 登録済み細目サイズ(例: M10x1.25)の `_d2_avg` / `_d_major_avg` / `_D1_minor_avg` が直接参照テーブルの値を返す。
7. **計算の通し**: `calc_thread_depth` を M16x1 の外ねじ・内ねじで呼び、`x_target` が有効径中間値から式どおりに求まる。

GUI の操作は手動で確認する(M16x1 を入力して生成、リスト選択の動作、他のねじ種類で手入力できないこと)。
